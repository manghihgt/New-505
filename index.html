📐 ลำดับเลขคณิต
พจน์ทั่วไป aₙ = a₁ + (n−1)d
ผลต่างร่วม d = a₂ − a₁
หาจำนวนพจน์ n = [(aₙ − a₁) / d] + 1
ตัวอย่าง: 2, 5, 8, 11, 14, ... → a₁ = 2, d = 3
📊 อนุกรมเลขคณิต
ผลบวก n พจน์ Sₙ = n/2 (a₁ + aₙ)
ผลบวก (อีกรูป) Sₙ = n/2 [2a₁ + (n−1)d]
ตัวอย่าง: S₅ ของ 1+2+3+4+5 = 5/2(1+5) = 15
🔢 ลำดับเรขาคณิต
พจน์ทั่วไป aₙ = a₁ · rⁿ⁻¹
อัตราส่วนร่วม r = a₂ / a₁
ผลบวก n พจน์ Sₙ = a₁(1 − rⁿ) / (1 − r)
ตัวอย่าง: 2, 6, 18, 54, ... → a₁ = 2, r = 3
